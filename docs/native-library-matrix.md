# Native library conformance map

Every library implementation in this map is Zig code compiled into `peony.wasm`. Python text in the linked tests is learner source. The native tests run through the one VM/Value/GC graph; the WASM and ESM tests instantiate the shipping artifact. The contract and excluded APIs are in the project plan §19; this file points reviewers to the executable checks for each admitted surface.

The shared [native bridge tests](../tests/unit/library_bridge.zig) additionally cover registry precedence, real class/exception identity, static binder errors, native object protocols, nested callback/input/iterator delivery, bounded work chunks, low-cap startup and reset. [Course programs](../tests/course-library.test.mjs) run word frequency, regex email extraction, CSV aggregation, mocked JSON HTTP, Path/copy graphs and input conversion end to end, plus deliberate exclusion imports. `node tools/diff_libraries.mjs` compares seven stable pure-library snippets with the installed CPython 3.12 oracle and labels its patch version; Python-source implementations and physical `.py` fixtures are absent. The local oracle run used **3.12.8**, while the intended release target is **3.12.14**. The [official 3.12.14 distribution directory](https://www.python.org/ftp/python/3.12.14/) contains source archives but no Windows binary; the differential tool accepts a `PEONY_CPYTHON` executable path for a later 3.12.14 run and does not present 3.12.8 as equivalent.
