# Peony

Peony is a small Python interpreter for learning in the browser. It lets learners write ordinary introductory Python, see what happens, change a line, and try again without installing a runtime. Its Zig engine runs as WebAssembly inside a Worker so the editor stays responsive.

Peony targets a deliberate subset of Python 3.12. Supported code should behave like Python; unavailable features should be explained clearly. The goal is a short, predictable path from an idea to a working program.
